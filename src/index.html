    Stylescape via npm

    This example demonstrates using Stylescape from npm with Sass compilation. Customize variables, import only what you need, and build optimized CSS.

    📦 Installation

    npm install stylescape

    Setup

    1. Import Stylescape in your Sass

    // src/scss/main.scss
@use "stylescape" as *;

    2. Customize Variables (Optional)

    // Override defaults before importing
@use "stylescape" with (
  $color-primary: #007bff,
  $font-family-base: "Inter", sans-serif
);

    3. Compile with Sass

    npm run build

    Components

    Accordion

    Why use npm?

    npm lets you customize Stylescape variables and import only the modules you need.

    Can I use Sass?

    Yes! Stylescape's source Sass files are included in the npm package.

    How do I customize?

    Override variables before importing Stylescape, or create your own components using the provided mixins.
